# 时屿洲音

《三角洲行动》手游口琴的**练习与提示工具**。作者：**时屿** · **时屿工作室**

## 是什么

- **练习模式**：界面就是手游口琴的复刻布局（8 音符键一行 + 上方 4 个调性键：半音/升调/自然音/降调），音符块落到按键上时按下；带判定、计分、等待模式、0.5×~3.0× 变速
- **三角洲模式（悬浮提示）**：把透明提示层叠在游戏上——只显示、静音、**不点屏幕、不读画面、不使用无障碍**；切调性时目标键"蓝=准备→绿=现在按"；悬浮球可拖动收起
- **曲谱导入**：数字简谱 / 光遇 SheetMusic 谱；自带"AI 生成提示词"（发给任意 AI 出谱）；可编辑、可自动补乐句间隔
- **音色工坊**：把游戏口琴的真实声音采样进练习模式（录屏 → 导入 → 自动识别音高并入库）

## 更新（App 内「更新中心」，无需配置）

| 文件 | 用途 |
|---|---|
| `update.json` | App 版本信息：手机在「更新中心 → 检查更新」自动读取 |
| `charts.json` | 云端曲库：手机点「检查并下载曲库」增量入库 |
| `apk/zhouyin.apk` | 当前版本的安装包（update.json 指向它） |

国内网络下 App 会用 jsDelivr CDN 加速读取，失败自动回退 GitHub 直连。

## 安全边界（写入产品）

提示层为**纯显示**：不注入任何输入、不读取游戏画面、不调用无障碍；仅限个人练习使用；游戏内若出现任何安全提示请立即停用悬浮功能。
